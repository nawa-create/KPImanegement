# デザインコンセプト - KPI Management

## デザイン哲学

> **"Less, but better"** - Dieter Rams

Appleのデザイン原則を参考に、**引き算の美学**を追求する。

---

## 1. コアプリンシプル

### 1.1 Radical Simplicity（過激なシンプルさ）

```
❌ よくあるUIの問題
- ボタンだらけ
- 情報過多
- 安っぽいグラデーション
- 無意味なアイコン

✅ 目指すUI
- 一画面に一つの目的
- 余白が主役
- 言葉で伝える（アイコン依存しない）
- 触りたくなる質感
```

### 1.2 Intentional Friction（意図的な摩擦）

すべてを簡単にしない。**大事な瞬間には、あえて立ち止まらせる。**

- 目標登録時: ゆっくり考えさせるアニメーション
- 達成時: 心に残るセレブレーション
- 失敗時: 責めずに、次を促す言葉

### 1.3 Emotional Connection（感情的なつながり）

数字だけでなく、**感情に訴えかける**表現。

```
❌ 「達成率: 73%」
✅ 「あと少しで、新しい自分に」
```

## 4. マイクロインタラクション

### 4.1 チェックイン完了

```
1. タップ
   □ → ✓ （瞬間的にチェック）

2. 波紋エフェクト
   中心から輪が広がる（0.3s）

3. 数値カウントアップ
   73% → 74% （滑らかに）

4. 触覚フィードバック
   軽い振動（haptic）
```

### 4.2 目標達成

```
1. 画面が一瞬暗転

2. 中央に大きく
   "達成"

3. パーティクルが弾ける
   （上品に、派手すぎない）

4. 3秒後に自然に消える
```

### 4.3 AIの思考中

```
┌─────────────────────────────────┐
│                                 │
│         ○ ○ ○                  │  ← 3つのドットが
│                                 │     波のように上下
│   あなたの目標を                │
│   分析しています...              │
│                                 │
└─────────────────────────────────┘

※ 一般的なスピナーは使わない
```

## 6. アニメーション指針

| 種類 | 時間 | イージング |
|------|------|------------|
| マイクロ（ボタン押下など） | 100-200ms | ease-out |
| 標準（画面遷移など） | 300-400ms | ease-in-out |
| 強調（達成時など） | 500-800ms | spring |

### 使用ライブラリ
- **Framer Motion** - 宣言的アニメーション
- **Lottie** - 達成時の祝福アニメーション

---

## 7. アクセシビリティ

- コントラスト比: WCAG AA準拠（4.5:1以上）
- タップターゲット: 最小44x44px
- フォントサイズ: 最小16px
- モーション軽減: `prefers-reduced-motion` 対応

---

## 8. アプリ名候補

| 名前 | 意味 |
|------|------|
| **ACHIEVE** | 達成する |
| **STRIDE** | 大股で歩く（前進のイメージ） |
| **FORGE** | 鍛える |
| **ORBIT** | 軌道（目標に向かう軌跡） |
| **PULSE** | 脈動（日々の積み重ね） |

→ **ACHIEVE** に決定
